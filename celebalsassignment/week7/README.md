# Week 7 - Delta Lake MERGE

## Overview
Implemented Delta Lake MERGE operations in Databricks using PySpark to
update existing employee records and insert new records.

## Files
-   employee_master_week7.csv
-   employee_incremental_week7.csv
-   notebook.ipynb

## Tech Stack
-   Databricks
-   Apache Spark (PySpark)
-   Delta Lake
-   SQL

## Workflow
1.  Load CSV datasets
2.  Create Delta table
3.  Perform MERGE
4.  Validate results
5.  View Delta History & Time Travel

## Outcome
Successfully demonstrated incremental data processing using Delta Lake.
