# Week 6 – PySpark Data Processing
## Overview

This repository contains my **Week 6** assignment completed during the **Celebal Technologies Data Engineering Internship**. The assignment focuses on understanding Apache Spark architecture, working with PySpark DataFrames, and performing data processing using CSV and Parquet datasets.

## Technologies Used
- Python 3.11
- Apache Spark (PySpark)
- Jupyter Notebook
- VS Code
- Git & GitHub

## Topics Covered
- Spark Architecture
- Driver, Cluster Manager & Executors
- Lazy Evaluation and DAG
- Spark Transformations & Actions
- Reading CSV and Parquet files
- DataFrame filtering and selection
- Column renaming and type casting
- Predicate Pushdown
- CSV vs Parquet performance
- Data export using Spark
